# Part 2 Tests: Control Flow and Block Structures

This folder contains programs for validating Part 2 requirements:

- `if`, `elif`, and `else` conditional branching
- `while` and `until` loops
- Nested block structures and scoping
- Correct control flow jump/label generation (if applicable) or nested IR grouping

## Run all tests

```bash
./parser/run_part2_tests.sh
```
