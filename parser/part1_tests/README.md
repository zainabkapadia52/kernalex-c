# Part 1 Tests: Expressions and Assignments

This folder contains small programs for validating Part 1 requirements:

- Standard arithmetic expressions and operator precedence
- Left and right associativity rules
- Unary operators (e.g., negative numbers, unary minus)
- Parentheses for overriding precedence
- Standalone assignments and declaration initializers

## Run all tests

From repository root:

```bash
./parser/run_part1_tests.sh
```

The script writes consolidated output to:

- `parser/part1_tests/all_table_outputs.txt`
