# KernaLex Compiler

A complete **lexical and syntax analyzer** for the KernaLex programming language, implemented using industry-standard tools: **Flex** (lexical analysis) and **Bison/Yacc** (syntax analysis).

## 🎯 Features

### Lexical Analyzer (Tokenization)
- ✓ **96 token rules** across 14 priority levels
- ✓ **Comment handling** (single-line `#`, doc `///`, multi-line `/** */`)
- ✓ **Numeric literals**: decimal, binary `0b`, octal `0o`, hex `0x`, floats, scientific notation
- ✓ **String/character literals** with escape sequences
- ✓ **34 keywords** and **32 operators** 
- ✓ **7 error categories** with accurate Line:Column tracking
- ✓ **Advanced error recovery** (panic mode + synchronization points)
- ✓ **Longest match** and **priority-based** rule ordering

### Syntax Analyzer (Parser)
- ✓ **~80 grammar rules** for C-like syntax
- ✓ **Function, variable, and struct declarations**
- ✓ **Control flow** (if/else, switch/case, while, for, repeat-until)
- ✓ **15 expression precedence levels**
- ✓ **Arrays, pointers, and struct access**
- ✓ **Syntax error detection** with automatic recovery
- ✓ **LALR parser** generated by Bison

## 🚀 Quick Start

### Build
```bash
make all          # Build both lexer and parser
```

### Run Lexer (Token Generation)
```bash
./kernalex test_parser.kl
```

**Output:**
```
[KEYWORD: int]
[IDENTIFIER: main]
[PUNCTUATION: (]
...
```

### Run Parser (Syntax Validation)
```bash
./kernalex_parser test_parser.kl
```

**Output:**
```
✓ Parsing completed successfully!
✓ No syntax errors detected.
```

- **GCC** or compatible C compiler

## 📖 Usage

### Lexer Only (Token Stream)
```bash
./kernalex <input_file.kl>     # Tokenize file
./kernalex                      # Read from stdin
```

### Parser (Syntax Check)
```bash
./kernalex_parser <input_file.kl>   # Validate syntax
```

Exit codes:
- `0` - Success (valid syntax)
- `1` - Errors detected

## 🎓 Implementation Details

### Architecture
```
Source Code → Lexer (Flex) → Token Stream → Parser (Bison) → Valid/Invalid
```

### Key Algorithms
- **Thompson's NFA→DFA** (via Flex)
- **LALR Parsing** (via Bison)
- **Panic Mode Recovery** with synchronization points
- **Longest Match** principle
- **Operator Precedence** parsing

### Performance
- **Time**: O(n) for both lexical and syntax analysis
- **Space**: O(1) (no AST yet)
- **Speed**: ~1M+ tokens/second
